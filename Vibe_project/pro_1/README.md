# 待办事项‍应用：

一个简单的任务管理工具（俗称 Todo L⁢ist），可以添加任务、‌标记完成、删除任务。

Vibe Coding提示词如下：

```
制作一个简单的待办事项Todo List网页应用

功能需求：
1. 添加任务：输入框，输入文字后点击添加按钮或者回车，新增一条待办任务
2. 标记完成：每条任务可以点击切换完成状态，完成的任务文字添加删除线，降低透明度
3. 删除任务：每个待办项带有删除按钮，点击即可删除这条任务
4. 基础体验：输入为空的时候不允许添加空任务

UI与布局要求：
1. 风格简洁现代，干净清爽，卡片式布局，整体页面居中，做响应式适配，手机端可以正常使用
2. 配色：柔和浅色系，主色用低饱和蓝，区分普通任务和已完成任务样式
3. 页面结构：标题、输入框+添加按钮区域、待办列表区域
4. 交互细节：按钮hover有过渡效果，任务新增有轻微平滑过渡，不要复杂花哨动画
5. 列表为空时，显示提示文字：暂无待办任务

额外要求：
1. 需要本地存储（保存刷新页面数据）
```
