# 个人名片网页

一个简洁美观的个人名片页面，展示名字、头像、自我介绍与联系方式。

Vibe Coding提示词如下：

```
请你帮我做一个个人名片网页(index.html)，要求：
1. 功能需求
	- 展示名字、头像(用占位图片替代，如picsum)、自我介绍、联系方法
2. 界面要求：
	- 界面呈现名片的大小
	- 色调体现出大气、美观
	- 布局合理
	- 简洁美观
3. 技术要求：
	- 使用HTML、SCSS、JavaScript
```



## 文件结构

| 文件          | 说明                                          |
| ------------- | --------------------------------------------- |
| `index.html`  | 页面结构，含可替换的姓名、头像、联系方式等占位信息 |
| `styles.scss` | 样式源码（SCSS）                              |
| `styles.css`  | 编译后的样式（由 `styles.scss` 生成，页面实际引用） |
| `main.js`     | 交互脚本：3D 倾斜 + 点击复制联系方式           |

## 使用方式

1. 直接用浏览器打开 `index.html` 即可预览（`styles.css` 已编译好）。
2. 在 `index.html` 中替换姓名、头衔、自我介绍、头像链接（`picsum.photos` 占位图）与联系方式。
3. 若需修改样式，请编辑 `styles.scss`，然后编译：

```bash
npm install -g sass
sass styles.scss styles.css
```

## 效果说明

- 深蓝金配色，整体大气简洁，卡片以标准名片比例（16:9）居中呈现。
- 鼠标在卡片上移动会有轻微 3D 倾斜，移出后平滑回正。
- 点击任意联系方式会将其复制到剪贴板，并在底部弹出提示。
- 移动端自动切换为上下布局。
