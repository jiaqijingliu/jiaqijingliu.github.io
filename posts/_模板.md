## 二级标题

- 列表项
- 行内代码写作 `code`

```js
// 代码块会自动高亮外面的样式（灰色底 + 等宽字体）
const a = 1;
```

> 引用块也可以。

写完这篇后运行：

```bash
npm run build:blog
```

然后 `blog/<slug>.html` 和两个列表就都更新了。

**注意**：以 `_` 开头的文件（包括本文件）会被跳过，不会被构建成文章。
